How to install (1 minute)

  1. Tap Download the app on your Android phone. If Chrome warns that the file might be harmful, tap Download anyway — it's warning about any app that doesn't come from the Play Store.
  2. Open the downloaded file. When Android asks, allow Install unknown apps for Chrome (or the app you downloaded with), then go back.
  3. Tap Install. If Play Protect shows "unknown developer", choose More details → Install anyway.
  4. Open DailyPropHub and allow notifications so you get new-pick and favorite-player alerts.

Updates: the app tells you when a new version is ready — tap the banner and install it over the top; your favorites and settings carry over. iPhone isn't supported yet.
